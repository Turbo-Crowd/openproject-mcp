# Code of Conduct

## Our pledge

We want participation in this project to be respectful, constructive, and welcoming for everyone.

## Expected behavior

- Be considerate in technical discussion and code review.
- Focus criticism on ideas, evidence, and implementation.
- Respect different experience levels, identities, and perspectives.
- Protect private data, credentials, and security reports.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, deliberate disclosure of private information, and disruptive conduct are not acceptable.

## Enforcement

Report a concern through GitHub's private vulnerability reporting feature or by contacting the maintainers through a private channel listed by the repository. Maintainers will review reports promptly and may remove content, warn participants, or restrict participation when needed.

This Code of Conduct applies to project spaces and public interactions representing the project.
