# Upstream Attribution and Sync

This repository is a Turbo Crowd-maintained fork of [alex13slem/openproject-codex-plugin](https://github.com/alex13slem/openproject-codex-plugin).

## Attribution

- Preserve the upstream Git history and the repository's MIT license notices.
- Credit upstream work in documentation and release notes when a change derives from it.
- Do not imply endorsement by the upstream authors, OpenProject GmbH, or any MCP client vendor.

## Sync policy

1. Review upstream changes before porting them.
2. Compare public API behavior, tool schemas, annotations, tests, and security impact.
3. Keep fork-specific safety defaults unless a reviewed change explicitly replaces them.
4. Record significant sync decisions in the changelog and include tests for adapted behavior.
5. Resolve license or attribution questions before merging a sync.

This document governs source attribution and maintenance intent. It does not authorize publication, releases, or automated upstream synchronization.
